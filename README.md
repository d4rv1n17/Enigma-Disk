# Enigma Disk

Приложение для Windows, которое отвечает на вопрос «куда делось место на диске».
WizTree и WinDirStat показывают, что лежит на диске сейчас. Enigma Disk делает снимки
и показывает, **какие папки выросли** за сутки, неделю или месяц.

## Возможности
- **Снимки дисков.** Быстрый многопоточный обход, сохраняются все папки от 1 МБ и 300 самых крупных файлов.
- **Что выросло.** Сравнение двух снимков. Показываются сами растущие папки, а не вся цепочка родителей
  (`Users → user → AppData → …`), и подсказка, что это за папка: кеш шейдеров, обновления Windows, Telegram и т. д.
- **Папки и файлы.** Навигация по снимку с размерами, долей от папки и изменением за неделю.
- **Очистка.** Только известные кеши: Temp, кеш браузеров, Discord и Teams, шейдеры видеокарты, дампы ошибок,
  обновления Windows, кеши разработчика, корзина. Занятые файлы пропускаются, ссылки и junction-папки не обходятся.
- **Ежедневные снимки** через Планировщик заданий Windows: без фоновой службы, с пониженным приоритетом.
- Тёмный интерфейс в стиле Enigma: чёрный, серый, белый и жёлтый акцент.

Все данные хранятся локально в `%LOCALAPPDATA%\EnigmaDisk`. В интернет ничего не отправляется.

## Сборка
Нужен .NET 10 SDK.

- Запуск для разработки: `dotnet run`
- Готовые файлы: запустите `build.bat`. В папке `dist` появятся:
  - `EnigmaDiskSetup.exe` — установщик, его можно отправлять другим;
  - `app\EnigmaDisk.exe` — та же программа без установки (портативная версия).

## Установщик
`EnigmaDiskSetup.exe` ставит программу в `%LOCALAPPDATA%\Programs\Enigma Disk` без прав администратора,
создаёт ярлыки в «Пуске» и на рабочем столе и добавляет программу в «Параметры → Приложения»,
откуда её можно удалить. Повторный запуск установщика обновляет программу. Исходники — в папке `Setup`
(.NET Framework 4.8, который уже есть в Windows 10 и 11, поэтому установщик почти не добавляет размера).

## Запуск без окна
`EnigmaDisk.exe --snapshot` делает снимки дисков из настроек и закрывается. Так его вызывает Планировщик.
